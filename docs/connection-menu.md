# Right-click a connection

What can be done with a connection on [Live](live.md) and [History](history.md), or with a line of
[Totals](totals.md). Right-click it for its menu; a right-click off the lines opens nothing.

## On Live and History

| | |
|---|---|
| **Expect this…** | opens [Expect this](expect-this.md), to add a rule for it to an expected list |
| **History of this destination** (Live), **Only this destination** (History) | its destination's connections over the last 7 days, on History: every connection to its name when it has one, or else to its address. Double-click does the same |
| **Copy address** | its address, to the clipboard |
| **Copy name** | its name, to the clipboard. Only when it has one |
| **Show the program in Explorer** | opens the program's folder with the program selected. Only when its path is known |

## On Totals

| | |
|---|---|
| **Show these connections** | the connections the line is made of, on History, for the same time. Double-click does the same |
| **Expect this…** | opens [Expect this](expect-this.md) for the latest of them, with the choice that fits the grouping already made: the network on **Networks**, the country on **Countries**, the address on **Addresses**, anywhere from the program on **Programs**, and anywhere to the port on **Ports** |
